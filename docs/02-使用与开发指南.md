# 使用与开发指南

> **English TL;DR** — Nexus Mod Browser is a Vortex extension that lets you search, browse and download Nexus Mods without leaving Vortex. It is an interim solution: Vortex's own "Browse Nexus Mods" page still only ships the Collections tab. MIT licensed — use, modify and redistribute freely. Requires Vortex 2.8+. Build with `node scripts/tsbuild.js` (no npm dependencies).

写给三类人：

- **普通用户** —— 想知道怎么装、怎么用、出问题怎么办 → §1–§6
- **想改代码的人** —— 想知道项目结构、怎么构建、怎么提 PR → §7–§10
- **只是路过的人** —— 看 §1 和 §11 就够

---

## 1. 这是什么

一个 **Vortex 扩展**，把 Nexus Mods 的 MOD 搜索、浏览、下载搬进 Vortex 里 —— 不用切浏览器。

**定位：过渡方案。** Vortex 自带的「Browse Nexus Mods」页面目前只提供整合包（Collections）标签，「模组」标签仍是占位状态。在官方 MOD 搜索功能上线之前，这个扩展用来补上这块空缺。

- **当前状态：正式版 1.1.0。** 新增插件语言切换（中文 / English）；N 网内容始终原样显示
- 非官方作品，与 Nexus Mods、Vortex 官方均无隶属关系
- 数据来自 Nexus 官方 GraphQL API，下载走 Vortex 自己的下载管道
- 许可证 MIT，可自由使用、修改、再发布

## 2. 功能

| 功能 | 说明 |
| --- | --- |
| 搜索 | 按关键词搜索当前游戏的 MOD，词干模糊匹配 |
| 排序 | 相关度 / 点赞最多 / 下载最多 / 最近更新 / 最新发布 |
| 卡片 | 封面、作者、分类、成人标记、下载量、点赞数、版本、简介 |
| 详情弹窗 | 点卡片上的 **Details / 详情** → 弹出主图 + 完整简介（N 网 BBCode 原样排版：粗体/链接/列表/图片），不列文件、不带下载按钮 |
| 前置检查 | 点 **Download / 下载** 时先查 N 网登记的必需前置：未安装的会列出来，可勾选一键下载、也可每行单独 Download / View page / Details；已安装的显示本地版本，站外组件与 DLC 只提示 |
| 一键下载 | 直接进 Vortex 下载队列，完成后自动安装 |
| 选择文件 | 一个 MOD 有多个主文件（如 R18 / 非 R18）时弹窗让你选 |
| 已安装标记 | 本地已有的 MOD 在卡片右下角标 `Installed !`（中文界面为 `已安装 !`） |
| 原生外观 | 复用 Vortex 自带的 UI 样式，跟随明暗主题 |
| 缓存 | 搜索结果缓存 5 分钟，切换页面不丢 |

**只下载主文件（MAIN）。** 可选文件、旧版本、已归档文件不会出现在选择列表里 —— 保证你拿到的是当前版本。

## 3. 安装

### 方式 A：在 Nexus 页面上点一下（最省事）

1. 在 Nexus Mods 打开本扩展的页面（Game：**Modding Tools** → Category：**Vortex Extensions**），切到 **Files** 标签
2. 点主文件右侧的 **Mod manager download**（Mod 管理器下载）
3. 会自动拉起 Vortex，Vortex 会弹出一个窗口，点窗口里的 **安装（Install）** 选项
4. 下载完成后重启 Vortex

> 这一步能成立，是因为发布包的文件名里带 `Extension` —— Vortex 靠文件名判断「这个下载是扩展还是游戏 MOD」。
> 如果页面上的文件是旧版本（文件名不带 `Extension`），请改用方式 B。

### 方式 B：把压缩包拖进 Vortex

1. 打开 Vortex，进入 **Extensions** 页面
2. 把下载的压缩包**拖进该页面**
3. 按提示重启 Vortex

### 方式 C：手动安装

1. 下载压缩包
2. 解压到 `%APPDATA%\Vortex\plugins\nexus-mod-browser\`
3. 确认 `info.json` 和 `index.js` **直接**位于该文件夹下（不要再套一层）
4. 重启 Vortex

> 三种方式装完效果完全一样，任选一种。方式 A 最省事，方式 B 最稳（不依赖文件名判断），方式 C 适合排查问题。

### 系统要求

- Vortex **2.8** 或更高
- 一个 Nexus Mods 账号，并在 Vortex 内登录
- 能访问 `api.nexusmods.com`

## 4. 使用

1. 在 Vortex 的 **Games** 页面激活一个游戏（这是「按游戏」页面，没激活游戏就不会出现）
2. 左侧导航点 **Nexus Mod Browser**（快捷键 `Ctrl + Shift + B`）
3. 输入关键词回车，或直接浏览默认列表
4. 页头右侧的**语言选择框**可切换 **中文 / English**；只影响插件自身 UI，N 网的 MOD 名称、简介、作者、文件名、分类、DLC、前置备注始终原样显示
5. 点 **Download / 下载** 下载并安装，或点 **View page / 查看页面** 在浏览器打开 MOD 页面
6. 如果这个 MOD 有**未安装**的 N 网前置，会先弹「需要的前置 MOD」：
   - 默认勾选所有未安装的前置 → 点 **Download selected** 一起下载，再继续当前 MOD；
   - 也可以点某一行的 **Download** 单独下，**View page** 去网页看，或 **Details** 在 Vortex 内看该前置的完整简介；
   - **Skip** = 不下载前置、继续当前 MOD；右上角 `×` / 点遮罩 / `Esc` = 整个操作取消；
   - 每行还有 **不再提醒** 勾选：勾上表示以后**任何** MOD 需要这个前置都跳过（灰色「不再提醒」小字），按"已安装"处理（不参与下载、没有下载勾选），重启 Vortex 后仍然有效；当它和其他前置一起出现时，取消勾选会恢复成「未安装」
   - 已安装的前置显示本地版本；DLC 和站外组件（VC++/.NET 等）只在弹窗已经打开时作为附注显示，不会单独触发弹窗
   - **所有 Nexus 前置都已安装（且没有未安装的）时不会弹窗**
7. 想先看完整介绍：点 **Details / 详情** 打开详情弹窗（主图 + 完整简介）。`Esc`、点遮罩、点右上角 `×` 都能关闭，长简介在弹窗内滚动

> 详情弹窗里的排版（粗体、链接、列表、图片、折叠块）直接复用 Vortex 自带的 BBCode 渲染器，
> 所以和 N 网页面上的观感一致；不会翻译正文。

## 5. 下载行为说明

### Premium 账号

点 Download →（如果有未安装的前置，先弹一次前置窗）→ 直接进队列 → 完成后自动安装。下载过程无额外弹窗。

### 免费账号

Nexus 不允许免费账号通过 API 直接拿下载链接，必须由用户在网页上"授权"一次。所以本扩展的做法是：

1. 点 **Download** → 自动打开浏览器到该文件的页面
2. 在网页上点 **Mod manager download**
3. 带授权信息的链接回到 Vortex，自动开始下载

> 网页上那一次点击无法省略 —— 这是 Nexus 对免费账号的限制，不是插件的问题。

### 前置（Requirements）

- 点 Download 时先查当前 MOD 在 N 网登记的必需前置，**查不到就直接继续下载**（不会卡住）；
- **只有存在「未安装」的 Nexus 前置时才弹窗**；全部已安装（或已设为不再提醒）就直接下载，不打扰；
- DLC / 站外组件（VC++/.NET 等）只在弹窗因为未安装前置而打开时显示，不会单独触发弹窗；
- 弹窗里勾选的前置会在你选完主文件之后、主 MOD 下载之前交给下载管道（后台，不阻塞主 MOD）；
- 前置**不显示 Downloading… / 进度**，只会在最后给一条汇总提示（Vortex 左侧「下载」页可以看进度）；
- 免费账号会逐个打开前置页面，每个页面都要点一次 **Mod manager download**；
- 每个前置自动取**主文件**（网站的 primary 文件，否则最新主文件），不会再弹一次文件选择框；
- 勾上「不再提醒」的前置会被持久化，按"已安装"处理（不参与下载），以后任何 MOD 需要它都跳过；当它随其它前置出现时可取消勾选恢复。

### 按钮状态

| 阶段 | 按钮 |
| --- | --- |
| 等待下载开始 | `Download`（可反复点击，重复点击会作废上一次等待） |
| 下载中 | `Downloading…`（禁用） |
| 结束 / 取消 / 超时 | 恢复 `Download` |

## 6. 常见问题

### 6.1 装好后左侧导航没有新条目

该页面属于「按游戏」分类，**必须先激活一个游戏**才会出现。去 Games 页面激活一个再回来。

### 6.2 列表一直是空的

- 确认网络能访问 `api.nexusmods.com`
- 确认已在 Vortex 内登录 Nexus 账号（错误提示里会显示 Log in 按钮）
- 部分很新的游戏在 Nexus 上还没有页面
- 点右上角刷新按钮重试

### 6.3 点 Download 打开了浏览器，而不是直接下载

免费账号的正常流程，见 §5。在网页上完成那一次点击后 Vortex 会自动继续。

### 6.4 从 Nexus 点「Mod manager download」后，提示安装了却没有出现

正常情况不会再有这个问题了 —— 现在的发布包文件名带 `Extension`，Vortex 会正确按扩展安装。

如果还遇到，通常是拿到了**旧版本文件**（文件名里没有 `Extension`）：

1. 在 Vortex 里切到当时激活的那个游戏 → **Mods** 标签
2. 找到那个被误装的条目（名字类似 `Nexus Mod Browser` 或 `nexus-mod-browser-0.6.x`）→ 删除
3. 改用 §3 方式 B：把 zip 拖进 **Extensions** 页面

> 原因：Vortex 只看文件名里有没有 `Extension`（`mod_management/util/queryGameId.ts`）。
> 有 → 按扩展安装；没有 → 当成普通游戏 MOD 装进当前游戏。

### 6.5 点了 Download 之后按钮像没反应

如果浏览器页面已经关了，**直接再点一次 Download** 即可，上一次的等待会自动作废。

（如果你等它超时，会看到提示「没有检测到下载：如果网页已关闭，直接再点一次 Download 即可」。）

### 6.6 某个 MOD 我明明装了，却没显示 `Installed !`

标记依据的是 Vortex 里记录的 **Nexus mod id**（`attributes.modId`）。通过本地压缩包、其他网站安装的 MOD 没有 Nexus id，因此无法匹配。

### 6.7 可以同时装多个游戏吗

可以。扩展是全局的，页面会跟随当前激活的游戏切换。

## 7. 卸载

- Vortex → **Extensions** 页面 → 找到 Nexus Mod Browser → Remove
- 或直接删除 `%APPDATA%\Vortex\plugins\nexus-mod-browser\` 目录
- 重启 Vortex

卸载不会影响已下载/已安装的 MOD。

## 8. 如何构建

仓库不含构建产物（`dist/` 已被 `.gitignore` 忽略）。**没有任何 npm 依赖，不需要 `npm install`。**

```bash
node scripts/tsbuild.js     # 编译 TypeScript → dist/（多文件 CommonJS）
node scripts/selftest.js    # 69 项单元测试
node scripts/smoketest.js   # 渲染冒烟测试（假数据）
node scripts/pack.js        # 打包成可上传的 zip → release/
node scripts/install.js     # 直接装到本机 %APPDATA%\Vortex\plugins\ 做本地调试
```

构建依赖：

- Node.js（任意较新版本）
- 一份 TypeScript 编译器 —— 脚本会优先用 VS Code 自带的 `tsc`，找不到就用 PATH 里的

为什么不用 webpack？Vortex 直接 `require()` 扩展目录里的文件，多文件 CommonJS 就够了；不打包也更容易调试和审计。

```

├── info.json                 # 扩展元数据（name / author / version / id）

├── README.md                 # 面向用户的简介
├── LICENSE / NOTICE          # MIT / 第三方资源说明
├── docs/
│   ├── 01-Vortex插件开发接口与方法.md   # 宿主接口调研（扩展开发者向）
│   └── 02-使用与开发指南.md             # 本文件
├── src/
│   ├── index.ts              # 入口：registerReducer + registerMainPage
│   ├── constants.ts          # URL / 分页 / 缓存 / action 名
│   ├── types.ts              # 数据模型
│   ├── nexus/                # GraphQL 传输层、查询、缓存服务
│   ├── bridge/download.ts    # ★ 下载桥接（扩展与宿主下载管道的唯一接口）
│   ├── state/reducer.ts      # session.nexusBrowser
│   ├── ui/                   # 页面、卡片、控件、图标、选文件弹窗、详情弹窗、前置弹窗
│   ├── util/                 # 游戏上下文、格式化、外链、已安装判定、文件分类
│   └── typings/shims.d.ts    # 最小的 react / node / vortex-api 类型声明
└── scripts/                  # 构建、测试、打包、安装、预览
```

## 10. 参与开发

### 提 Issue

请带上：

- Vortex 版本（Help → About）
- 现象 + 复现步骤
- 控制台报错（Vortex 里按 `Ctrl + Shift + I` 打开 DevTools）

### 提 PR

- 改动先跑 `node scripts/tsbuild.js && node scripts/selftest.js`，必须全绿
- 新增逻辑请补测试（`scripts/selftest.js` 里按现有风格加）
- 不要引入 npm 依赖 —— 项目刻意保持零依赖、可离线构建
- UI 只用宿主已有的 `nxm-*` 类名，不要自造 Tailwind 类（样式是按需编译的，不存在的类会静默失效）

### 几个硬性约定

| 约定 | 原因 |
| --- | --- |
| 只能用 `nxm://` + `start-download` 下载 | 不要自己拼 CDN 直链，会绕过授权与校验 |
| `init(context)` 里只能注册，不能干活 | 它会被调用两次（主进程 + 渲染进程） |
| 不要 `import` 宿主内部路径（`@/...`） | 那些路径只存在于 Vortex 源码里 |
| `info.json` 的 `version` 要和发布版本一致 | 否则扩展不会更新 |

## 11. 已知限制

- 只能**读**公开数据，不能收藏、订阅、点赞（需要写权限的 API）
- 只显示当前激活游戏的 MOD
- 详情弹窗只能显示**一张**主图（Nexus 的 Mod 类型没有多图/画廊字段），主图加载失败会自动回退缩略图
- 前置清单只包含**作者在 N 网 Requirements 区域登记**的内容；写在简介正文里的需求识别不了
- 前置的版本要求没有结构化字段（N 网 API 只返回自由文本 notes），所以插件只展示备注和本地版本，**不做版本拦截**
- DLC 前置无法检测是否已拥有；站外组件（VC++ / .NET 等）无法自动安装，只能打开链接
- 免费账号一键下载前置会逐个打开浏览器页面，每个页面仍需手动点一次授权（§5）
- 免费账号必须经过一次网页授权（§5）
- 成人内容目前不做过滤，按 Nexus 默认行为显示
- 暂无设置页、无多语言（界面以中文为主，卡片按钮为英文）

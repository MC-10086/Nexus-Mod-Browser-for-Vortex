[b][size=4]English[/size][/b]
A lightweight Vortex extension for searching and downloading Nexus Mods without leaving the mod manager. It shows complete descriptions, checks prerequisites, sends main files to Vortex's download queue, and opens card covers / detail images in a fullscreen viewer. The interface supports Chinese, English and Japanese; Nexus content is always shown as returned by the API, without translation.

[b][size=4]中文[/size][/b]
一个轻量的 Vortex 扩展，让你不用离开 MOD 管理器就能搜索和下载 Nexus Mods。它提供完整简介、前置检查、主文件下载，以及卡片封面 / 详情主图的点击放大。界面支持中文、English 和 日本語；N 网内容始终按 API 原文显示，不做翻译。

[*]Click card covers or the detail image to zoom in fullscreen. / 点击卡片封面或详情主图可全屏放大。
[*]Native Vortex look, follows light and dark themes. / 原生 Vortex 外观，自动跟随明暗主题。
